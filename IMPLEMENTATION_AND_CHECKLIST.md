# AI Mystery Auditor — исправленная версия 7

## Реализовано

- Единая граница хранения проверок через `AuditRepository`.
- Общие данные Supabase для проверок, уведомлений и административных справочников.
- Supabase Auth для производственного режима; локальные роли остаются только демо-режимом.
- RLS-доступ по ролям и `primary_approver_id`.
- Серверная проверка разрешённых изменений шоппера и руководителя.
- Аудиофайлы вынесены в закрытый Supabase Storage.
- Шоппер не выбирает руководителя и после отправки видит только свои проверки и статус.
- Уточнение шоппера возможно только после запроса аудитора.
- Точное время: часы 00–23 и минуты 00–59.
- Бренды, города и регионы берутся из общего справочника.
- Кассовая дисциплина для контрольной закупки вводится вручную и не определяется по аудио.
- Для Mystery Shopping касса и cross-sell имеют статус N/A.
- Sales Drivers считаются отдельно от BPV.
- Отсутствие доказательства не считается соблюдением критерия.
- Предпросмотр и печатный PDF показывают четыре одинаковых ключевых индекса.
- Удалена глобальная красная подсветка ручных полей.
- Руководителю первой открывается главная очередь в реестре.
- Финальные проверки сохраняются в реестре и учитываются в дэшборде.

## Перед производственным тестом

1. Создать проект Supabase.
2. Последовательно выполнить:
   - `supabase/migrations/20260729_init.sql`;
   - `supabase/migrations/20260729_02_runtime_repository.sql`.
3. Создать пользователей в Supabase Auth и соответствующие записи в `profiles`.
4. Добавить переменные из `.env.example`.
5. На сервере задать `GEMINI_API_KEY`; ключ нельзя вводить или хранить в браузере.
6. Выполнить один сквозной тест:
   - шоппер создаёт проверку и загружает аудио;
   - аудитор открывает её, выполняет анализ, проверяет критерии и выбирает руководителя;
   - руководитель утверждает или возвращает с обязательным комментарием;
   - проверить реестр, дэшборд, PDF и историю действий.

## Важно

SQL-миграции ещё не запускались на реальном проекте Supabase, потому что доступ к вашему проекту не предоставлялся. До подключения Supabase приложение работает в явно ограниченном локальном демо-режиме.
